*Technical Context:* Generative AI was used as a software engineering, code-review, literature-search and research-audit assistant (Claude Code for coding, verification, literature search, audit of the research and review of drug feasibility against FDA labels; Gemini 3.1 Pro to generate code). No dataset file (FASTQ, BAM or VCF) was uploaded or attached to any AI assistant. The coding assistant (Claude Code) ran the pipeline locally. All scoring, filtering and the report tables were produced by the deterministic Python code of this repository (`track2.run_pipeline`, `track2.build_candidates` and the modules they call), executed locally and, once, on Google Colab; the AI assistants did not produce the rankings, which come from that code.

*Work phase (up to 2026-10-18):* the main sessions ran in Claude Code (Claude Sonnet 5 and Claude Sonnet 5.5). Claude Opus and Claude Sonnet ran as sub-agents with three roles: annotators of sentences for direction (benefit or harm) and relevance in the engine experiments, auditors (red-team reviews of the research and of the submission files), and writers of code and tests. In the main sessions the assistant also (1) implemented the protocol amendments in the code and ran the analyses locally and, once, a CPU runtime of Google Colab to test the notebook; (2) read the text of official US drug labels (DailyMed and openFDA), recorded a reading of each label's paediatric status with verbatim quotes, and wrote a code check that every quote appears in the label it cites; (3) searched and read the primary literature through Europe PMC, with the same rule that each sentence it reports must be found in the source text by code, and assigned the evidence levels and the direction (benefit or harm) of each sentence from a written definition; (4) audited the research with red-team reviews and checked the FDA approval status of each drug; (5) drafted the text of the report, the methods description and the follow-up plan. In the later uses, up to 2026-10-18, it also supported the engine experiments, the language-model annotation of public literature sentences, the signature-reversal analysis (line E), the line C adjustment for lineage and proliferation, the computational follow-ups and the audits of the deliverables. The sub-agents saw only public literature sentences, gene symbols, drug names and the categorical case profile (no coordinates, alleles, cDNA or sample identifiers). The author directed each step, decided every amendment, reviewed the results and approved the deliverables. The label readings and the evidence labels are the assistants' readings, not a pharmacist's, a regulator's or a specialist's review, and are marked as such in the deliverables. No FASTQ, BAM or VCF was provided to any assistant in any phase.
