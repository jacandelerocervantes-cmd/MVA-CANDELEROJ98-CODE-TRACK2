# Data access and provenance

Third-party data are not uploaded to this repository (`data/` is ignored by git). This file states, for each resource, where it was obtained, how access is requested or obtained, and how it was used, so that the work can be reproduced without the files being redistributed. It is built only from the repository's own records (`data/sources/record.json`, `data/depmap/download_record.json`, `data/lincs/record.json`, `data/geo/record.json`, `data/gdsc/record.json`, `data/models/revisions.json`, `out/license_check.json`, `out/data_manifest.json`, `THIRD_PARTY_LICENSES.md`, `README.md`, `docs/data_protection.md`) and the fetch code in `src/track2`. Where neither a record nor the code nor the file on disk states something, the cell says "not recorded" followed by the reason. Sizes and SHA-256 of the files present under `data/` were recomputed from the files on disk; wherever a record held a size or hash, the recomputed value equals it (no mismatch). A date written "file date on disk" is the modification time of the file, not a date stated by a record. "Fetch command" means a module and arguments that exist in `src/track2`; where none exists the cell says so. No patient data, reads, VCFs or genomic positions are described or distributed here.

Licence column: short form taken from `THIRD_PARTY_LICENSES.md` and `out/license_check.json`. "Derived tables" means tables under `out/` that carry fields derived from the resource; raw files are never redistributed.

## Reproducing without the files

Commands are only those that exist in `src/track2` (checked against the code) and in `README.md`; no others are implied. Run with `PYTHONPATH=src`. Sizes and SHA-256 below were recomputed from the files on disk and equal the values in the records.

1. `python -m track2.fetch_sources --list`, then `python -m track2.fetch_sources --only <source>` for each named source (`primekg`, `hpo_annotations`, `hpo_ontology`, `mondo`, `mgi`, `omnipath`, `depmap_crispr`, `depmap_covariates`). It writes `data/sources/record.json`; compare the size and SHA-256 there with the values above. The MGI files are not on disk, so their values are the recorded ones only.
2. `python -m track2.depmap_download` (DepMap Model, expression and PRISM files from figshare articles 25880521 and 25917643; the file URLs are resolved from the figshare API at run time; MD5 is checked on download and a failed check deletes the file; `--list` shows what would be fetched), then `python -m track2.prism_l4 --out out`. Compare with `data/depmap/download_record.json` (MD5) and the SHA-256 in the tables.
3. STRING v12.0, ChEMBL (release ChEMBL_37 as recorded in the manifests) and Reactome (release 97) are fetched into `data/` on the first pipeline run (`python -m track2.run_all`, or `python -m track2.run_pipeline` / `track2.from_submission`; the ChEMBL universe is built by `track2.chembl_universe.build_universe()`, which has no command line of its own); compare with `out/data_manifest.json`.
4. `python -m track2.get_vina && python -m track2.docking_structures` (AutoDock Vina 1.2.7 and the PDB structures; `pip install -r requirements-docking.txt` first). Compare the Vina file with `tools/vina_download_record.json`.
5. The LINCS Enrichr libraries, GSE22206, GPL6104 and the GDSC2 workbook: no fetch command exists in the repository (`line_e.py` and `cf9.py` only read the local files). Fetch the URLs in the tables and compare size and SHA-256 with `data/lincs/record.json`, `data/geo/record.json` and `data/gdsc/record.json`.
6. Hugging Face models: `python -m track2.engine_v4 download` fetches the two models (weights and tokenizer files only) and writes `data/models/revisions.json`; note that it pins to the commit current at run time, so to reproduce the results use the revisions recorded in that file and compare the file hashes.
7. Orphadata files are downloaded and cached by `track2.disease_landscape` and `track2.engine_benchmark`; no version or date is recorded.
8. The gated hackathon dataset: request access from the organisers under the Hackathon Rules and Data Transfer Agreement (the steps and the dataset version are not recorded; no record in the repository); then `python -m track2.track1_extract` (or use `config/track1_gene_level_extract.json` as committed).
9. Live services (DailyMed, openFDA, Europe PMC, NCBI E-utilities, ClinicalTrials.gov, CPIC, Open Targets, UniProt, QuickGO, SigCom LINCS) are queried by the pipeline stages listed by `python -m track2.run_all --list`; their release and the end of the read window are not recorded (no record in the repository).
10. Check outputs: `python -m track2.verify_outputs` compares the outputs with `out/checksums.sha256`. Outputs that embed live service text are marked network-dependent in that file and can differ from the recorded hashes.

## Terms that matter for reuse

Only the restrictions already listed in `THIRD_PARTY_LICENSES.md`:

- ChEMBL is share-alike (CC BY-SA 3.0): candidate tables with ChEMBL-derived fields are released under CC BY-SA 3.0.
- CPIC is CC BY-SA 4.0, research purposes, not for sale as a commercial item; tables with CPIC-derived fields should be CC BY-SA 4.0.
- GDSC allows only non-transferable internal research and educational use and restricts redistribution; publish only derived summary fields.
- HPO forbids altering its content and logical relationships; cite the consortium and show the file version and date.
- ClinicalTrials.gov requires attribution, the processing date and a statement of modifications; some records carry third-party copyright.
- OmniPath contains sources with non-commercial or share-alike licences; `out/signed_effect.json` carries derived fields.
- Enrichr asks for a licence for commercial use.
- Europe PMC abstracts and full text keep their publishers' copyright; only short verified sentences are used and no abstracts or full text are redistributed.
- DailyMed label text may include material protected by the labelers.
- Open Babel is GPL-2.0 (optional, installed by the user, not redistributed).
- The gated hackathon dataset may not be redistributed and must be deleted upon conclusion of the hackathon (Hackathon Rules and Data Transfer Agreement).
- Raw source files are not redistributed; derived tables under `out/` carry derived fields, so tables with CPIC-, GDSC- or OmniPath-derived fields should carry those terms or be limited to summaries.
