# Addendum: computational follow-ups CF1 to CF9 (written before any of them was run)

Status: pre-specification. Language: English. Written after reading `protocol/follow_up_experiments_v2.md` (section 3 and the triage table, section 2) and `out/experiment_plan.json`, and after reading the code and stored outputs that the checks reuse (not their results for these tests). Nothing below was computed when this file was written. No criterion is changed after a result is seen; if a check turns out to be impossible as specified, it is reported as "not estimable" or "not runnable", never silently modified.

## 0. Scope and reading rules

- These checks are exploratory and post hoc. They cannot prove efficacy, safety or dose for any person. A candidate that "survives" stays a hypothesis; it has only not been refuted by this check. A candidate that is "refuted" is closed as a computational candidate (the triage of `protocol/follow_up_experiments_v2.md` decides what follows: hazard-class rows stay in the hazard panel and the toxicity design H1).
- Verdict words: **survives** = the pre-specified refutation criterion is not met (and every control stated for that CF is passed); **refuted** = the criterion is met (or a stated control fails); **not estimable** = the statistic cannot be computed for that candidate with the data on disk (node or targets missing, too few observations); nothing follows for the row; **not runnable** = the whole CF cannot be executed with data on disk and the project caches (the reason and what would be needed are stated).
- Data: only files on disk and the project caches. No download. Europe PMC is used only in CF3 (cursorMark, at most 4 requests per second, cached in `data/cache`). No patient data are used: gene symbols, drug names and the categorical case profile only; no coordinates, cDNA or sample identifiers.
- Seeds: 20261018 unless stated. Multiplicity: where a CF tests several candidates with a p-value, Benjamini-Hochberg q across that CF's candidates, rule q < 0.10 (the threshold used throughout the project). Single-test CFs use p <= 0.05, one-sided where stated.
- Every number in the outputs is computed by `src/track2/computational_followups.py`; the outputs are `out/computational_followups.json` (sorted keys) and `out/computational_followups.md`.

## CF1. Line C sign audit (resolved by documentation)

- Plan definition: sign audit of line C: state whether positive rho means higher viability (resistance) at a high checkpoint score; recompute with an orientation-explicit sensitivity metric.
- Plan refutation criterion: Lazertinib and Neratinib are dropped as "vulnerabilities" if the sign means resistance.
- Concerns: Lazertinib, Neratinib (and, as the same convention, the four tubulin-class survivors).
- Resolution fixed now: the sign convention is verified in the code. Checkpoint score = mean over cell lines of z-scored log expression of BUB1B, BUB1, BUB3, MAD1L1, MAD2L1, TTK (`prism_l4.sac_scores`, `multi_evidence_completion.line_c_drug_level` definition text); low score = weak checkpoint. The response variable is the PRISM log fold change of viability (negative = fewer cells = more sensitive; Bortezomib is the positive control of the screen). Spearman rho between viability and score is therefore positive when low-score (weak-checkpoint) lines have lower viability, i.e. rho > 0 = more lethal in weak-checkpoint lines. The same orientation is documented in `vulnerability_core.py` (`diff` = weak quartile mean minus strong quartile mean, negative = more lethal when the score is weak).
- Implementation (check, not a new test): (a) quote the definition strings and code lines with their file and line numbers; (b) orientation sanity: the median log fold change of the screen's positive-control and tubulin drugs across lines must be negative (a drug that kills lowers the value); (c) orientation-explicit metric: delta = mean viability in the weakest score quartile minus mean viability in the strongest quartile (lines with finite viability; quartiles of the same score; no adjustment), reported with the adjusted partial rho of `line_c_adjusted`. Convention: delta < 0 = more sensitive when the checkpoint is weak.
- Verdict rule: **survives** (resolved) if the documentation says rho > 0 = more lethal in weak-checkpoint lines, orientation sanity (b) passes, and delta < 0 with rho > 0 for the drug; **refuted** if delta > 0 (the sign would mean resistance). The check tests the sign, not the biology: the adjusted association is correlational, from cancer cell lines, and does not model partial loss.

## CF2. Tubulin-class enrichment among line C survivors

- Plan definition: hypergeometric test of the four tubulin-class survivors among the 190 estimable drugs.
- Plan refutation criterion: if enriched, the score is treated as a mitotic-dependency control, not a source of candidates; the four stay hazard-class.
- Concerns: Colchicine, Eribulin, Paclitaxel, Vincristine.
- Implementation fixed now: the line C adjusted analysis of `line_c_adjusted` is re-run unchanged on the same pool (partial rank correlation with lineage fixed effects and ranked proliferation covariate, 1,000 within-lineage permutations, BH across estimable drugs, seed 20261018) to obtain all estimable drugs (population M, expected 190). Tubulin class = the members of class `a_tubulina` of `out/caution_list.json` (pre-existing definition), matched to the pool by exact upper-case name or by first-word stem. K = tubulin-class drugs among the estimable ones. Survivors = original hits (original q < 0.10) whose adjusted analysis survives (adjusted q < 0.10, same sign), n = their number (expected 6); X = tubulin-class drugs among them (expected 4). Statistic: P(X' >= X) for a hypergeometric(M, K, n). Sensitivity (not decisive): the same test with the draws being all estimable drugs with adjusted q < 0.10 irrespective of the original hit status.
- Verdict rule: **refuted** (enriched, so the score is read as a mitotic-dependency control and the four stay hazard-class, closed as a source of candidates) if p <= 0.05; **survives** (no evidence that the hits are only the tubulin class; the four still stay hazard-class and in H1) if p > 0.05; **not estimable** if K < X or fewer than 3 survivors.

## CF3. Engine specificity

- Plan definition: rank of each drug for BUB1B against degree-matched random genes.
- Plan refutation criterion: drug not above the null: close the row.
- Concerns: Olaparib, Tyrosine, Progesterone, Zinc Chloride, Vorinostat.
- Implementation fixed now: the frozen engine scores a drug for a gene set from the literature co-mention of drug and gene plus a prior, and its engine rank for these five drugs rests on co-mentions with the class genes. The gene-specific input is reproduced as the Europe PMC hit count of publications up to 2024 (the engine's maximum year) whose title or abstract names both the drug and the gene: `(TITLE:"drug" OR ABSTRACT:"drug") AND (TITLE:"gene" OR ABSTRACT:"gene") AND PUB_YEAR:[1900 TO 2024]`, resultType lite, pageSize 1, cursorMark=*, hitCount read. Only this literature leg is tested; the engine prior leg cannot be re-scored for random genes without re-running the engine and is not tested (stated limitation).
- Null: 99 random genes drawn without replacement, degree-matched to BUB1B by the degree of the gene in the STRING v12 physical network at score 700 (degree within +-25 % of the BUB1B degree, widening to +-50 % if fewer than 99 genes are available), excluding the genes of the case and of the checkpoint (BUB1, BUB1B, BUB3, MAD1L1, MAD2L1, TTK, TRIP13, CEP57, CENATAC, CENPE, IGBP1, CDC20) and symbols shorter than 4 characters (alias collisions). Statistic: the drug-gene hit count for BUB1B against the 99 null genes; empirical one-sided p = (1 + number of null genes with count >= observed) / 100, ties count against the drug. BH q across the five drugs.
- Verdict rule: **survives** if p <= 0.05 and q < 0.10; **refuted** otherwise (including an observed count of 0); **not estimable** if the Europe PMC query cannot be answered (never inferred as zero).
- Limitation: "tyrosine" also matches "tyrosine kinase" and "zinc chloride" is rarely named in abstracts; the null genes share this bias, so the comparison is fair but coarse.

## CF4. Graph path audit (line A)

- Plan definition: list drug-to-disease paths; check each edge for a source and for generic hub nodes.
- Plan refutation criterion: all paths pass through hubs or lack a primary source: close.
- Concerns: Pomalidomide, Disopyramide.
- Implementation fixed now: PrimeKG as used by line A (`knowledge_graph.load_graph`: symmetric adjacency without drug-disease and drug-effect edges). Query nodes of line A = the MVA disease node and the phenotype nodes found for the six case terms (as in `out/kg_query_e5.json`). Drug nodes = the PrimeKG drug nodes matched to the candidate name by `kg_query.universe_match`. Hub = a node whose degree is at or above the 99th percentile of the degree over all graph nodes. A path is "hub-free" when none of its intermediate nodes is a hub (endpoints excepted). For each drug and query node: the shortest path length with hubs allowed, the shortest hub-free path length (breadth-first search with hub nodes removed as intermediates, lengths up to 4), and up to five example hub-free paths with node names, node types and edge relation types. Source of an edge: PrimeKG records no per-edge primary-source field in the on-disk table (columns relation, display_relation, x_index, y_index), only the relation type and the source of each node; the edge relation type and endpoint node sources are listed, and the "lacks a primary source" branch is reported as "not assessable per edge" and is not used to refute. The refutation therefore rests on the hub branch (and on the absence of any path).
- Verdict rule: **survives** if at least one hub-free path of length <= 4 reaches a query node; **refuted** if no hub-free path of length <= 4 exists (all paths pass through hubs, or there is no path); **not estimable** if the drug has no node in the graph.

## CF5. Scheme sensitivity for B2

- Plan definition: recompute support under the other weighting schemes and against random genes.
- Plan refutation criterion: not in the top set under any other scheme: close.
- Concerns: Ceritinib, Selinexor, Tirbanibulin (B2 support came from scheme W3 only, two-record links).
- Implementation fixed now: (a) schemes: from the stored two-record core module scores (`out/core_n2/core_threshold_scores_sub_*.json`), recompute the combined score of `consensus.combined` for W1 (epcr weights), W2 (equal weights) and W3 (pathogenic gene only) at STRING 400, 700 and 900; "top set" under a scheme = the top 20 at all three thresholds (the definition of `track1_scenarios`); report the rank per scheme and threshold. (b) random genes: the BUB1B core module (two-record links, same exclusion of generic complexes) is replaced by 100 random modules of equal size drawn degree-matched node by node (`proximity` degree bins) from the STRING 700 network, the proximity z of every drug is recomputed with the same procedure (300 degree-matched random modules for each z, seed 20261018), and each candidate's rank among all scored drugs is compared with its rank for the real module recomputed with the same settings. Empirical one-sided p = (1 + number of random modules in which the drug ranks at least as well as for the real module) / 101. BH q across the three drugs.
- Verdict rule: **refuted** if the drug is not in the top set under W1 nor under W2 (the plan's criterion), or if the random-module control fails (p > 0.05 with q >= 0.10); **survives** if it is in the top set under at least one other scheme and the random-module control passes (p <= 0.05 or q < 0.10); **not estimable** if the drug has no scored targets.

## CF6. Line D sign permutation

- Plan definition: sign-permutation null and re-check of the control drugs.
- Plan refutation criterion: net effect inside the null range: close.
- Concerns: Regorafenib, Sunitinib, Nirogacestat, Ritlecitinib, Erdafitinib.
- Implementation fixed now: the signed OmniPath network of `signed_effect.SignedNetwork` is rebuilt. Observed net effect = the stored net of the drug (sum over its targets of the signed path effect), recomputed from the drug's stored targets and action signs and required to equal the stored value. Null: 1,000 permutations that shuffle the signs of the signed edges among the existing edges (topology and the number of positive and negative edges fixed), recomputing the net effect of the same targets with the same action signs. "Null range" = the central 95 % of the null net effects; empirical two-sided p = (1 + number of permutations with |net| >= |observed|) / 1,001. BH q across the five drugs. Control re-check: the six textbook perturbations are evaluated on every permuted network; the observed number recovered (4 of 6, two of them by construction because they are direct readout nodes) is compared with its null distribution (P(recovered >= observed)); the same for the four non-readout controls (2 of 4 observed).
- Verdict rule: **survives** if the observed net lies outside the null range (p <= 0.05) and q < 0.10; **refuted** if inside; the control re-check is reported as context and, if the control p exceeds 0.05, the line is flagged "controls not above chance" (the drug verdicts are kept but the reading line says so); **not estimable** if the drug has no targets in the network.

## CF7. Line E-P leave-one-array-out

- Plan definition: leave-one-array-out on the 2 case versus 4 control arrays; reversal in the BUB1B and Track 1 signatures.
- Plan refutation criterion: reversal q at or above 0.10 in any leave-out, or concordance with the disease signature: close or flag hazard (DESIGN CHOICE threshold).
- Concerns: Neratinib, Amphotericin B, Auranofin, Fluvastatin, Nelfinavir.
- Implementation fixed now: GSE22206 (one adult lymphoblastoid cell line, 2 case and 4 control arrays) and the Chem Pert consensus library are used exactly as in `line_e` (signature of 100 up and 100 down genes, minimum |d| 0.5, expressed genes above the median, truncation 150 of the drug signatures, reversal R, null from 1,000 random expressed-gene signatures with seed 20261019, BH across matched drugs). The full six-array signature is first reproduced and must equal the stored one (self-check). Then each of the six arrays is left out in turn (four leave-outs of a control: 2 vs 3; two leave-outs of a case: 1 vs 4); when a group has one array its variance is taken from the other group (stated now because the original estimator needs two arrays per group). Per leave-out: R and q for reversal (BH over all matched drugs) of each candidate. Disease-signature concordance: the stored `gene:BUB1B` and `track1_combined` results at N=150 of `out/line_e_signature_reversal.json`; a drug is concordant with the disease signature if it carries the hazard flag in either (q for mimicry < 0.10 with R < 0 and below the null mean). The reversal q in those two signatures is reported as information only.
- Verdict rule: **refuted** (close or flag hazard) if q_rev >= 0.10 or R <= 0 in any of the six leave-outs, or the drug is concordant with the disease signature; **survives** if q_rev < 0.10 and R > 0 in all six leave-outs and it is not concordant; **not estimable** if the drug is not in the matched drug set.

## CF8. IGBP1 axis network distance

- Plan definition: network distance IGBP1 to MTOR/AMPK nodes against degree-matched random pairs.
- Plan refutation criterion: distance not shorter than null: drop the IGBP1 rationale from X1 (not the drugs).
- Concerns: Sirolimus, Everolimus, Metformin (the X1 group; the verdict applies to the rationale, not to the drugs).
- Implementation fixed now: STRING v12 physical network, score 700 (400 and 900 as sensitivity), largest connected component, as in `string_net`. Target nodes: MTOR, PRKAA1, PRKAA2. Observed statistic = the mean over the three targets of the shortest-path distance from IGBP1. Null: 5,000 random pairs in which the source is drawn from the degree bin of IGBP1 and each target from the degree bin of its own node (`proximity.degree_bins`), excluding the real nodes; statistic = the mean distance over the three targets. One-sided p = (1 + number of null draws with statistic <= observed) / 5,001; the distance to each target and to the MTOR and AMPK sets separately are also reported.
- Verdict rule: **survives** (the rationale is kept in X1 as a hypothesis) if the observed mean distance is shorter than the null (p <= 0.05); **refuted** (the rationale is dropped from X1, the drugs are not) otherwise; **not estimable** if IGBP1 or all targets are absent from the network.

## CF9. Second drug-sensitivity screen for the line C survivors

- Plan definition: only if a second screen is already on disk; otherwise not performed.
- Plan refutation criterion: no same-sign association: close.
- Concerns: the six line C survivors (Lazertinib, Neratinib, Colchicine, Eribulin, Paclitaxel, Vincristine).
- Implementation fixed now: a second screen counts only if the same drug appears in the PRISM compound list in a different screen (column `screen`: REP.PRIMARY, REP.1M, REP.300) or if another drug-sensitivity resource (GDSC, CTRP or PRISM secondary) is on disk. If so, the adjusted analysis of `line_c_adjusted` is applied to that row alone and "same-sign association" means the adjusted partial rho has the original sign with permutation p <= 0.05. The DepMap CRISPR gene-effect matrix is a different assay (gene knockout, not drug sensitivity) and is not accepted as a second screen. If no drug has a second independent row, CF9 is reported "not runnable" with the reason and what would be needed; nothing is downloaded.
- Verdict rule: per drug **survives** (same sign, p <= 0.05), **refuted** (no same-sign association), or CF9 as a whole **not runnable**.

## Triage mapping after the checks (fixed now)

- A hazard-class row (Colchicine, Eribulin, Paclitaxel, Vincristine) never becomes a benefit candidate through CF2 or CF9; its toxicity design H1 stays.
- A "comp" row (ENG, A, D, EP) that is refuted is closed as a computational candidate; one that survives its CF stays a hypothesis with that check passed, and needs a laboratory design before any further claim.
- A "lab" row whose CF is refuted is closed; one that survives goes to the laboratory design named in the triage (X4 for Lazertinib and Neratinib, X5 for Ceritinib, Selinexor and Tirbanibulin, X1 for the IGBP1 axis candidates); rows with several CFs need all of them passed.
- Rows whose verdict is "not estimable" or "not runnable" keep their previous status.

## CF9 execution (before running) - written 2026-10-18

Status: pre-specification of the execution of CF9; the CF9 definition, the refutation criterion and the triage mapping above are unchanged. Written after downloading the screen and after listing its drug names and columns (to learn that it has no synonym column and which survivors are named in it); no association with the checkpoint score was computed before this section was written.

- **Screen.** GDSC2 fitted dose response, GDSC release 8.5, file `GDSC2_fitted_dose_response_27Oct23.xlsx` (21,330,376 bytes) from `https://cog.sanger.ac.uk/cancerrxgene/GDSC_release8.5/`, openly downloadable without login or click-through. It is an independent assay (Sanger, 72 h resazurin/Syto60 viability, fitted curves) from PRISM (Broad, pooled barcoded lines, 5 days). Licence: the Sanger / Genome Research Limited terms published at `https://www.cancerrxgene.org/legal` (files provided as is; research and educational use; no warranty); no click-through is needed to fetch the file and none was accepted. The URL, date, size and SHA-256 are in `data/gdsc/record.json`. The file is stored in the git-ignored `data/gdsc/gdsc2_r8_5/`.
- **Drug matching.** A survivor (LAZERTINIB, NERATINIB, PACLITAXEL, VINCRISTINE, COLCHICINE, ERIBULIN) is matched to a GDSC `DRUG_NAME` when, after upper-casing and removing non-alphanumeric characters, the GDSC name equals the survivor name or any synonym listed for it in the PRISM compound list (column `Synonyms`, same keys as `prism_l4.compound_keys`). GDSC has no synonym column, so matching is by name only on the GDSC side. No fuzzy matching. A drug with several GDSC rows per line is averaged per line.
- **Cell-line matching.** GDSC line to DepMap `ModelID` through `data/depmap/Model.csv`: first `SANGER_MODEL_ID` = `SangerModelID`; if absent, `COSMIC_ID` = `COSMICID`; if still absent, the upper-case alphanumeric cell-line name equals `StrippedCellLineName` (upper-cased) or `CellLineName`. A match is kept only if the model has an expression profile (checkpoint score and proliferation covariate from `prism_l4.sac_scores`, as in line C) and a lineage (`OncotreeLineage`). Ambiguous matches (one GDSC line to several models, or the reverse) are dropped and counted. The matching coverage (GDSC lines, matched by each key, retained) is reported.
- **Response measure.** Primary: `LN_IC50` as given (natural-log IC50 in uM; lower = more sensitive, the same orientation as PRISM viability, so the sign convention of line C is unchanged: score low = weak checkpoint; rho > 0 = more lethal in weak-checkpoint lines). Secondary, reported only: `AUC` as given (lower = more sensitive). The verdict uses LN_IC50 alone.
- **Statistic.** The same as line C (`line_c_adjusted.partial_perm`): partial rank correlation of the response with the checkpoint score, lineage fixed effects (`OncotreeLineage`, lineages with fewer than 10 matched lines pooled) and the ranked proliferation covariate, with the 1,000-permutation null of the score within lineage, seed 20261018, two-sided. The original sign is the sign of `original_rho` in `out/line_c_adjusted.json`. BH q is computed across the drugs estimable in CF9 (for one estimable drug q = p) and reported together with p.
- **Criterion (unchanged from the CF9 definition).** survives = adjusted rho has the original sign and permutation p <= 0.05 (the BH q < 0.10 for the same drug is reported as a secondary reading and does not change the verdict); refuted = estimable and not (same sign and p <= 0.05); the per-drug verdict applies only to drugs with a retained independent row.
- **Not estimable.** The drug (name or synonym) is absent from GDSC2, or fewer than 100 matched lines have a finite response (the same minimum as line C). An absent drug is never imputed from a related drug (vinblastine, docetaxel and others are not substitutes). CF9 as a whole is "not runnable" only if no survivor is estimable; the estimable ones act as positive/control check of the pipeline (paclitaxel, if present), not as candidates, because hazard-class rows never become benefit candidates through CF9.
- **Consequence mapping.** Lazertinib and neratinib: survives keeps the hypothesis (laboratory design X4); refuted closes them as computational candidates; not estimable keeps their previous status, with the note that no independent screen covers them. Tubulin drugs: stay hazard class whatever the result.
- **Outputs.** `out/computational_followups_cf9.json` (sorted keys) and `out/computational_followups_cf9.md`, computed by `src/track2/cf9.py` (reader `src/track2/xlsx_min.py`, standard library only). Correlational, from cancer cell lines, post hoc; no patient data.
