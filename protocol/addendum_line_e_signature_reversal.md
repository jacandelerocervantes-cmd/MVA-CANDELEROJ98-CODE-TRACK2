# Addendum: line E, signature reversal (fifth computational line)

Written before any score was computed. Label of every output: **exploratory; hypotheses for follow-up; never evidence of efficacy; not a treatment or dose recommendation.**
Only gene symbols and public data are used. No coordinate, cDNA change or sample identifier of the child is read, printed or stored.

## 1. Status and unchanged rules
* Line E is the fifth line, added to A, B1, B2 and C (D stays exploratory). The rule of "at least two usable lines" of the earlier addenda is UNCHANGED and is still the rule for the report.
* Line E gives a separate, additional route to a CANDIDATE (section 7). A candidate is a hypothesis for follow-up, never evidence of efficacy.
* Failure to produce any candidate is reported as is.

## 2. Data (authorised downloads, recorded in `data/lincs/record.json` and `data/geo/record.json`, each file with URL, date, size, SHA-256)
* Enrichr libraries `LINCS_L1000_CRISPR_KO_Consensus_Sigs` (knockout consensus signatures, gene symbol + Up/Down) and `LINCS_L1000_Chem_Pert_Consensus_Sigs` (chemical perturbation consensus signatures, name + Up/Down). Both are consensus over cell lines (cancer lines); no cell-line-specific signature is in these libraries, so the cell-line sensitivity analysis cannot be run and is reported as not available.
* Gene order inside a set is taken as given (assumed to be ranked by the library's consensus score; not verifiable from the file). Truncation to the first N genes relies on this assumption.
* One GEO series matrix: GSE22206 (homozygous BUB1B variant, one adult proband; lymphoblastoid and fibroblast cells; Illumina GPL6104). Its use is fixed in section 6.

## 3. Disease signatures (each reported separately)
1. Per-gene knockout signatures: BUB1B (primary); every other curated MVA gene of `out/mva_landscape.json` (BUB1, BUB3, CENATAC, CEP57, MAD1L1, TRIP13) that exists in the CRISPR library; the number of those absent is reported (CEP57, TRIP13 and others are already known to be absent from the library).
2. Track 1 gene list = genes of the Track 1 gene-level ranking (`candeleroj98_genomewide_ranking.csv`, columns rank, gene, type, n_high_impact, log10_joint_rarity, phenotype_score only; the `variants` column is never read) plus the genes of `config/track1_gene_level_extract.json` (structural list). Every such gene with a knockout signature in the library is scored separately (same null, same FDR). The number of Track 1 genes, and how many have a signature, is reported. Mechanism genes = the curated MVA genes plus CENPE (mitotic kinesin of the same checkpoint pathway); other Track 1 genes are non-mechanism genes.
3. Track 1 combined signature (rule fixed now): weight w_g = phenotype_score of the gene, with a floor of 0.05 (so every Track 1 gene with a signature contributes; genes of the structural list with no phenotype_score get 0.05). For each gene g in the library, vote v_g(x) = +w_g if x is in the Up set of g's knockout, -w_g if in the Down set; the combined score of a gene x is the sum of votes. Combined Up = the genes with positive net score, ordered by score; combined Down likewise; each is truncated to N (section 4). Variant "Track 1 high-score only": same rule but only genes with phenotype_score >= 0.10 (a stated threshold). If it reduces to BUB1B alone this is stated.
4. GEO patient signature: section 6.

## 4. Drug side, scoring and null
* Drug side: the Up and Down sets of each drug in the chemical library whose name matches the project's approved small-molecule list (`data/universe.json`: ChEMBL max_phase 4, molecule type Small molecule; names matched upper case, then with salt words removed, as in `track2.fda_approved.candidate_names`). The number of library drugs matched and of project drugs matched are reported; unmatched names are not guessed.
* Truncation: primary N = 150 genes per set (drug and disease), sensitivity N = 50, and the full set.
* Reversal R = |D_up ∩ S_down| + |D_down ∩ S_up| - |D_up ∩ S_up| - |D_down ∩ S_down|.
* Null: 1,000 random knockout signatures (seed 20261018) drawn without replacement from the CRISPR library after excluding every curated MVA gene and every Track 1 gene (control signatures of unrelated genes), truncated to the same N. For the combined signature the null draws, per replicate, as many random genes as the Track 1 gene count in the library and gives them the same weights in a random order, then applies the same rule.
* p_reversal = (1 + #{null R >= observed R}) / 1001 (upper tail); p_mimic = (1 + #{null R <= observed R}) / 1001. Benjamini-Hochberg across drugs separately for each tail and each signature.
* A drug is "line E usable" for a signature only if FDR_reversal < 0.1 AND R > 0 AND R exceeds the null mean (correct direction, reversal, not mimicry). Line E supports a drug if it is usable for BUB1B (primary) and/or the Track 1 combined signature; the output lists every gene signature that supports the drug. A drug usable only for non-mechanism or off-target gene signatures (and not for BUB1B or the combined signature) is flagged "reversal not tied to the mechanism" and does not count.
* "Concordant" drugs (FDR_mimic < 0.1 and R < 0, i.e. they mimic the knockout) are flagged as hazards.

## 5. Sensitivity analyses
(a) N = 50 versus N = 150 versus full set; (b) BUB1B alone versus the MVA gene set (union of the curated MVA genes present in the library, combined by the same vote rule with equal weights) versus the Track 1 combined signature and its high-score variant; (c) cell-line-specific signatures: not available in these consensus libraries. Reported as concordance of the sets of usable drugs.

## 6. GEO patient series (method fixed before any expression is read)
Design: lymphoblastoid arrays only, proband (2 arrays) versus unrelated controls (4 arrays; relatives are excluded as carriers of unknown status); same cell type. Statistic per probe: difference of mean log2 intensity divided by (pooled standard error + s0), s0 = median pooled standard error over probes; Up = the 150 highest, Down = the 150 lowest statistics with a mapped gene symbol. This needs the platform annotation (GPL6104) to map probes to genes; the platform file is not part of the authorised download and is not fetched. If no gene annotation is available locally, the GEO signature is NOT computed and this is reported as is. The series is a different adult individual with a different variant and two replicates per sample; it would be a supportive signature, not a model of the child.

## 7. Combination rule (fixed now)
A drug is a CANDIDATE only if all hold: (1) line E usable (section 4); (2) at least one of the four existing lines usable for that drug (A specific set, B1 robust set, B2 two-record set, C supported set of `out/four_lines_review2.json`; B2 counted as prespecified, and B2 held exploratory shown as a second reading); (3) the safety layers do not exclude it: not in `out/caution_list.json` classes, not oncology-cytotoxic (ATC L01 or a caution-list class member: tubulin, mitotic checkpoint, genotoxic chemotherapy, proteasome), and the entries of `config/proposal_safety.json` are shown beside it (a boxed warning is displayed, not hidden); (4) an FDA label exists (`out/fda_approval_check.json` confirmed). Age support is reported per band 0-4, 5-11, 12-17 years from the label tables; unknown age is never assumed.

## 8. Controls
* Positive control (pre-specified): MTOR knockout (present in the library) versus the mTOR inhibitors sirolimus, everolimus, temsirolimus. MTOR knockout should be mimicked by them (concordant, the mTOR inhibitors reproduce the loss of MTOR); the pipeline is judged to recover the control if at least one of these drugs lies in the top 5% of the mimicry ranking (most negative R) for MTOR, with the reversal ranking given beside it. Also run for other genes whose inhibitors are present (e.g. a gene with a known approved inhibitor in the library) and reported without selection. Note that for a knockout the expected relation of an inhibitor is mimicry, not reversal; both ranks are reported.
* Negative control: 20 random library genes (not MVA, not Track 1) as pseudo-disease signatures; the fraction of usable drugs is reported (expected near the FDR level).
* Whether the control is recovered is reported whatever the outcome; if it fails, line E is declared not interpretable.

## 9. Limits (reproduced in the outputs)
A knockout signature is not the partial loss of function of the child; the consensus signatures come from cancer cell lines; the signature of one gene knockout is dominated by generic proliferation and stress genes, which the null addresses only partly; names not matched are lost; the project's other lines do not support the nine report drugs, so line E cannot rescue them. The statistics are descriptive, with 1,000 nulls the smallest p is 1/1001.

## 10. Addendum of 2026-10-18: patient-derived signature P (GSE22206), fixed before it is computed
Authorised extra download (this task only): the GEO platform annotation GPL6104 (`GPL6104.annot.gz`, 4,584,978 bytes by the HEAD request, under the 100 MB limit), in its own new git-ignored directory `data/geo/GPL6104/`, recorded in `data/geo/record.json` with URL, date, size and SHA-256; read only with `python -I`. Section 6 above is not altered; this section fixes the details it left open.
* Groups, read from the series-matrix metadata (`!Sample_title`, `!Sample_source_name_ch1`, characteristic "cell type"): cases = the two arrays titled `LCL-proband-*` (lymphoblastoid cell line of the affected proband); reference = the four arrays titled `LCL-control*` (two unaffected controls, same cell type). Relatives (`LCL-relative*`) and fibroblast arrays are not used (carrier status unknown; different tissue; the single fibroblast control is not replicated). This is ONE adult patient with a homozygous BUB1B variant (n = 1 patient, two technical/biological replicate arrays): no between-patient inference is made; the signature describes that cell line against two controls.
* Probe-to-gene collapse: each probe is mapped to one gene symbol by the annotation (probes with no symbol or several symbols separated by "///" are dropped); per gene the probe with the highest mean log2 expression over the six arrays is kept.
* Expression filter: a gene is "expressed" if its mean log2 expression over the six arrays is at or above the median of all kept genes.
* Statistic: on the values as deposited (already log2): d = mean(proband) - mean(controls); t = d / (pooled SE + s0), s0 = median pooled SE over genes (SAM-like moderation, controls as reference). Signature P: among expressed genes with |d| >= 0.5 (log2), the 100 with highest t as Up and the 100 with lowest t as Down (fewer if the filter leaves fewer; the number is reported).
* Null: with 6 arrays the design allows only 15 label permutations, too few for 1,000 draws; therefore the null is 1,000 random signatures of the same size (100 Up + 100 Down, disjoint) drawn from the expressed mapped genes (seed 20261019); the same truncation to the library gene index applies to the real and to the random signatures.
* Score, one-sided reversal and mimicry p-values, Benjamini-Hochberg across drugs, usability (FDR < 0.1, R > 0, R above the null mean), hazards, and the combination rule are exactly those of sections 4 and 7; P is added as a signature that can support line E next to BUB1B and the Track 1 combined signature ("line E usable" if usable for BUB1B, the Track 1 combined signature, or P; the output lists which). The earlier results are unchanged.
* Limitation, stated up front: the cell line of one adult patient (a different variant, a transformed lymphoblastoid line, two controls) cannot represent the child, and a signature of 100 + 100 genes from n = 1 is noisy; P is supportive and exploratory only.
